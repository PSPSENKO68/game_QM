Nhập Liệu Nhanh từ file Excel / CSV

Sao chép dữ liệu bảng tính của bạn dán thẳng vào đây hoặc upload file để nạp hàng trăm câu hỏi hoặc user tức thì

Chưa chọn file

Hướng dẫn định dạng cấu trúc CSV:

Nhân Viên:

employee_code,full_name,department,pin,total_score,is_active,max_plays 0902223333,Hoang Quoc Huy,Phòng Công Nghệ,5555,100,true,3 0913334444,Phan Thu Trang,Phòng Hành Chính,6666,0,true,5

Lưu ý: Cột "employee_code" là SĐT hoặc Email đăng nhập của nhân viên. Dòng tiêu đề viết chính xác. Cột max_plays là giới hạn lượt chơi của riêng nhân viên đó (để trống nếu muốn áp dụng giới hạn chung).

Danh sách Câu hỏi Đề thi (Nhập cột tương tự như sau):

Câu hỏi,Answer 1,Answer 2,Answer 3,Answer 4,Đáp án đúng Thời gian bắt đầu làm việc buổi sáng là mấy giờ?,08:30 sáng,09:30 sáng,10:30 sáng,Thỏa thích tự do,1 Quy trình xin nghỉ phép từ 3 ngày trở lên cần báo trước mấy ngày?,5 ngày,3 ngày,2 ngày,Không cần báo trước,1

Lưu ý: Cột "Đáp án đúng" nhận giá trị số từ 1 tới 4 tương đương với các câu trả lời đúng từ Answer 1 đến Answer 4.
